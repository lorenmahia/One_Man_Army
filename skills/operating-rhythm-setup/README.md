# Operating Rhythm Setup

> A light set of goals, weekly metrics, monthly updates, a decision log and a risk register with kill criteria, sized for one person.

## When to use it

- "Help me set quarterly goals and track them properly."
- "What should I review every week as a solo founder?"
- "Draft a monthly investor update template for me."
- "I keep drifting. How do I decide when to stop a project?"

## What you get

- **Quarterly OKRs** with baselines, committed versus stretch labelled
- **A 5-10 metric weekly scorecard** with written definitions and a review template
- **A monthly update outline**, including how to report a bad month
- **A decision log** and **a five-row risk register** with a continuity note
- **Go / adjust / stop kill criteria** and runway scenarios
- **An offer to build** the dashboard, scheduled refresh and calendar items

## How it works

```
Intake questions -> Honest note on evidence -> OKRs -> Weekly scorecard
   -> Monthly update -> Decision log + risks + kill criteria
   -> Optional dashboard, refresh and calendar
```

## Boundaries

- The playbook found no independent evidence that OKR or EOS systems cause better results; only the cheap primitives are borrowed.
- Examples are illustrative, and benchmarks are directional ranges.
- Research and planning support only; not legal, tax, investment or financial advice.
- It never sends updates or creates calendar items without your go-ahead.
