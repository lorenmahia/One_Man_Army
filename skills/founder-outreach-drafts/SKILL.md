# Founder outreach drafts

Short messages get replies. Each message should state who the sender is, why this person, and one specific ask that is easy to say yes to.

## Steps

1. **Check the venture.** Confirm which venture the message is for. Use saved wording only if it describes this venture. Never carry over a name, website or product from a different project; that would confuse the recipient.
2. **Check saved voice.** If the user has saved a tone or opener for outreach, follow it. If the saved opener does not fit, write a neutral version and say so in one line.
3. **Write the message.** Three parts, under 90 words:
   - Who you are, in one line.
   - Why this person, with one specific reason from their public work.
   - One ask: a 15-minute call, a single question, or an introduction. Name a time window.
4. **Write variants.** Give one message for peers and one for senior people or regulators. Regulators and officials get a formal route, not a cold message.
5. **Do not send.** Present drafts for the user to send. Never send on the user's behalf without explicit approval.
6. **Track follow-up.** Suggest one follow-up date, five to seven days later, with a short second line.

## Boundaries

- Use only public professional information about the recipient.
- Do not guess email addresses.
- Do not include personal details the user has not chosen to share.
