# Long-form report builder

A long report written in one pass drifts and loses sources. Build it in stages: outline first, then sections, then one check.

## Steps

1. **Confirm scope.** Ask for the topic, the reader, the length or depth, the output format, and any sections they must have. Ask one round of questions only.
2. **Scaffold the outline.** Create the document with a title and one pending block per section. Each pending block gets a short intent line that says what the section must answer.
3. **Research before writing.** Run the searches for all sections in parallel batches before writing any prose. Keep a source list as you go, with a date for each source.
4. **Fill one section at a time.** Replace each pending block with its content. Each section ends with a one-line "so what". Put facts, estimates and inference in separate labelled lines.
5. **Charts and tables.** Use a table where the reader will compare. Add a chart only when it shows a trend the table cannot.
6. **Verify.** Re-check every figure against its source. Confirm each section answers its intent line. Flag unverified items in an "open questions" section.
7. **Deliver.** Share the document, then give a short summary: the main finding, where the open questions are, and the next step.

## Rules

- Mark which sources were only seen as search snippets, not opened.
- Do not quote more than a short phrase from any source.
- If the topic involves money, law or health, add the relevant "not advice" line once, at the top.
- If the document is long, check it in parts rather than all at once.
